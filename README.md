# bractlabs Community

Questions, ideas and feedback for Bract Engine and Bract Racer.

[Website](https://bractlabs.com) · [Play Racer](https://bractlabs.com/games/racer/) · [Engine overview](https://bractlabs.com/engine/) · [Showcases](https://bractlabs.com/showcases/) · [Discussions](https://github.com/bractlabs/community/discussions)

## Start Here

Use **Discussions** for questions, ideas and sharing experiments. Use **Issues** for reproducible bugs in the public playable build. Read the organization's [contribution guidelines](https://github.com/bractlabs/.github/blob/main/CONTRIBUTING.md) and [code of conduct](https://github.com/bractlabs/.github/blob/main/CODE_OF_CONDUCT.md) before participating.

## Source Availability

| Project | Status |
| --- | --- |
| Bract Racer | Open-source release planned soon; repository, license and contribution instructions will be announced when ready. |
| Bract Engine | Not open-source; engine source access is shared under corporate agreements. |

This repository is a community space, not the game's source repository or an engine source distribution. No game or engine software license is granted here. Corporate access inquiries: [info@bractlabs.com](mailto:info@bractlabs.com).

## Before Reporting a Bug

Search for an existing report, include the public build URL and reproduction steps, and describe your browser, operating system and GPU if known. Racer is an early, unpolished build, and Bract is not yet production-ready.

Never post credentials, cookies, personal data or proprietary code. Report security concerns privately using the [security policy](https://github.com/bractlabs/.github/blob/main/SECURITY.md).
